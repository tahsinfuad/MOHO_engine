# MOHO Engine

MOHO Engine is a game engine currently in its early stage of development.

## Requirements

1. A C/C++ compiler (GCC/G++ is preferred)
2. A GPU with support for OpenGL 4.1 or higher
3. Makefile support (e.g., `mingw32-make`)

## Build Instructions
 
Open a command prompt in the project's root directory and run: migw32-make

The executable will be generated upon successful compilation.

## Current Features

This project is in its initial stage of development, so no notable features are available yet.

## Planned Features

1. A dedicated Python-based engine editor
2. An expanded MOHO Engine library
3. Full modular plugin support
4. A Lua scripting engine
5. Improved input mapping
6. A physics engine for 2D and 3D games
7. Enhanced asset management
8. Full multithreading support
9. Audio support
10. Resource management with graph and log views
